# B.S. Awareness branding

The BSA mark combines an eye (awareness) with a north/navigation chevron. Geometry uses rounded strokes and simple 24-unit proportions to visually coexist with Lucide icons while remaining an original BSA mark.

- `bsa-app-icon.svg` — dark launcher/social icon
- `bsa-mark-transparent.svg` — in-app/map/Android Auto mark
- `bsa-monochrome.svg` — themed/one-color use
- `bsa-wordmark.svg` — full B.S. AWARENESS wordmark

Palette: Night `#081116`, Ice `#F4F7F8`, Awareness Blue `#20A4E8`.
