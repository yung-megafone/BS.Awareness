# BSA Brand Palette

This palette normalizes the colors from the selected August 2026 branding mockup.

| Token | Hex | Intended use |
|---|---|---|
| Deep Navy | `#081F33` | Primary backgrounds |
| Slate Blue | `#103B5C` | Secondary map/UI surfaces |
| BSA Blue | `#0A8FE8` | Android Auto / information accent |
| Awareness Green | `#2E8E57` | Primary awareness accent |
| Bright Green | `#3FCB70` | Active/high-emphasis accent |
| Graphite | `#495057` | Neutral markers / muted UI |
| Silver | `#A0AACC` | Secondary text / borders |
| Near White | `#F2F7FB` | Primary light text |
| Hazard | `#F1A72C` | Warning / hazard POIs |
| Info | `#119FF2` | Information POIs |
| Fuel | `#7958C7` | Fuel POIs |

## Notes

- The **minimal icon** is the preferred launcher/application mark.
- The **default scenic icon** is an optional alternate icon and works well as repository/social artwork.
- The core mark is intentionally simple: navigation arrow + awareness horizon + road.
- UI icons should continue to use **Lucide** rather than vendoring a duplicate icon set into this folder.
