# B.S. Awareness

**B.S. Awareness (BSA)** is a privacy-conscious, open-source mapping and
navigation client built around OpenStreetMap.

BSA is designed around a simple idea: a navigation application can tell you
more about the environment you're traveling through than merely how to reach
your destination.

It combines everyday points of interest—fuel, food, businesses, parking,
lodging, and services—with mapped infrastructure such as surveillance and
traffic-monitoring equipment.

> **Status:** Alpha software. BSA is under active development and should not
> be relied upon as the sole source of navigation or safety-critical
> information.
